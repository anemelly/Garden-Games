# Garden Games (V1.1)

Little hand-drawn pastel games, made with Claude.

- **Omok Garden**: five in a row on a 15 × 15 garden. Play Claude on hard, or watch two Claude bots play each other with move-by-move notes.
- **Garden of Life**: a 2–8 player pass-and-play life board game. Careers, family, homes, a garden stock market and a casino. Claude bots are optional.

Play it: open the GitHub Pages link for this repository. On a computer, use the install button in Chrome or Edge's address bar to add it as an app. On iPhone, open it in Safari, tap Share, then Add to Home Screen.

Saved games, records and settings stay in each browser on each device.
